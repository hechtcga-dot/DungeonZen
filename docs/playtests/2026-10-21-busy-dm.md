# Playtest 2026-10-21: busy DM (2 yrs 5e, Roll20 + notes app, not technical)

Fresh install, no AI service. Small town campaign: new campaign, own world map, 6 cards, 3 links, storyline + 2 acts, prep sheet, encounter, live session, player view, Roll20.
Run: skill `playtest`, driver `tests/e2e/play.mjs`. 0 window/console errors.
Example campaign: `examples/example_Millbrook/` (ships as `example_Millbrook.zip`; names in this report are the ones used while playing, swapped for invented ones in the example).

## Works well
- Start screen: clear, 3 choices. Getting started guide (map → regions → notes) short, can skip anywhere.
- Import own map picture: one click, shows at once.
- New card: name already selected, type and Enter. Cards place themselves without overlap.
- Link window after pin-to-pin drag: kind list, secret/clue, "players know this". Secret shows dashed with label.
- Session prep page: one-page test box, opening line auto-links card names, "Select existing…" pulls board secrets in, NPC row picks an existing card.
- Encounters: SRD search instant ("bandit" → Bandit, Bandit Captain), count +/−, XP and difficulty live, offline Suggest works.
- Live desk: start session, +1 h, quick-log, hour picture, advisor box. Player view clean, Esc gets back.
- Card sheet: Export ▾ › Export to Roll20 there.

## Bugs
1. **Board red pins hidden (FIXED).** Cards cut off their own pin; dragging where the hint says moved the whole board. No way to tie a link by drag.
   → Fix: done: cards leave room for the pin; smoke checks every pin can be grabbed.
2. Second act on a storyline gets the same default time as the first (Day 1 0:00–Day 2) and sits exactly on top of it: act 1 disappears. Also starts before "now" (Day 1 09:00).
   → Fix: Add an act starts at the end of the storyline's last act (first act: the current time), one day long. Acts that overlap in one lane stack in two rows instead of covering each other.
3. Session prep › Add an NPC: new row lands below the screen, focus stays on the button; clicking anything else removes it as empty ("Empty row removed"). Looks like the button does nothing.
   → Fix: every Add-a-row button (NPC, scene, thread, secret) scrolls the new row into view and puts the cursor in its first field. Empty-row cleanup waits until the DM has been in the row and left it.
4. Quick-log: Enter does not log (only the Log it button).
   → Fix: Enter logs, Shift+Enter makes a new line; hint under the box says so.
5. Parchment background shows a hard seam (two tiles not matching) on Timeline, What they know, card sheet panels.
   → Fix: make the parchment texture seamless (or one picture stretched over the panel); add the seam to the look checks (compare pixel rows either side of the tile edge).
6. Link window: after switching Link → Secret it says "No cards yet: Add link" though both cards are kept and saved.
   → Fix: Secret and Clue show the same two cards as Link did (the cards the DM dragged between).

## Confusing
- Guide's "Have an AI draw one" says "Settings › AI services": there is no Settings.
  → Fix: say "AI services (✦ button at the bottom of the left rail)" or put a Choose an AI service… link right there, as other screens do.
- Unticked checkboxes are dark filled squares ("The players know this", "Show hidden links"): read as ticked.
  → Fix: unticked = light box with a dark border; ticked = filled with a tick. Both skins.
- Add an act window opens with focus on × close, not on Act title.
  → Fix: every window puts the cursor in its first field on open (× never first).
- Encounters: "For 4 characters of level 1" though no PCs exist; nothing says "add your party first". Suggest offered a Sahuagin raid (sea) for an inland town when Where was left empty.
  → Fix: no PCs → line "No party yet: Add a player character" with the button; count and level come from the party once there. With no place picked, Suggest leaves out sea-only and other habitat-bound creatures.
- Drop-downs in the narrow Suggest column cut their words ("Where the party is (not placed", "Any creatur").
  → Fix: Where on its own full-width row, shorter labels ("Party's place"), and add drop-downs to the look checks (cut text).
- Prep pacing says "All planned scenes played" at 0:00 with no scenes planned.
  → Fix: no scenes → "No scenes planned"; the "all played" line only when there were some.
- Map is named after the file ("Sword-Coast-world").
  → Fix: on import, name it "World map" with the name selected to type over (or ask for a name in the guide step).
- Free-text quick-log "Toblen grateful" doesn't count as meeting Toblen; player view "People you have met: Nobody yet".
  → Fix: a logged note that names a card (auto-link already finds names) offers "Mark as met: Toblen?" in one click; the DM approves (rule 2).

## Feels missing
- Import notes without AI: no way to just keep a .txt as a notes file.
  → Fix: "Keep as notes files" button on the Import notes screen (copies into the notes folder, names auto-linked); AI reading stays the optional second step.
- Roll20: only per card (sheet › Export). Expected a campaign-wide export next to "Export to Foundry VTT or Owlbear Rodeo"; Find (Ctrl+K) "roll20" finds nothing.
  → Fix: Setup › "Export to Roll20…" (pick cards, default all NPCs/monsters) using the existing per-card export; Find lists every Setup and Export action by name.
- Map: no way to pin an existing Location card as a point; only draw a region.
  → Fix: "Put a card on the map": pick a Location/Building card, click the map = a small marker region; card sheet gets "Show on map".
- Add a PC where it's needed: Live desk, Map, Encounters say "add them on the desk" with no button.
  → Fix: the message becomes a button "Add a player character" that opens the same window as the desk's.
- Player view shows "Uncharted" until the party token is placed, even with a world map.
  → Fix: with no token, show the world map (no token, no secret regions); the hint stays for the DM.
- Planned encounter doesn't show in Live desk "Tonight's prep".
  → Fix: Tonight's prep lists the session's encounters with an Open button.

## Recommendations (most first)
1. **Add a player character from anywhere it's missing** (Live, Map, Encounters, Players) — first-run DMs hit the "no party" wall on 4 screens. Small.
2. **New rows and windows put the cursor where you type** (Add an NPC/scene/thread, Add an act, every window) — 3 findings, feels broken today. Small.
3. **Acts don't stack on each other**: new act after the last one, overlapping acts in two rows — the Timeline is the storyline view and hides acts now. Medium.
4. **Notes without AI**: keep imported files as notes, AI optional — the guide's "Import my notes" is a dead end without an AI service. Medium.
5. **Roll20 for the whole campaign in Setup, and Find knows every action** — Roll20 is this DM's table; hunting per card is slow. Medium.
6. **Checkbox look** (clear unticked state) — misreads "The players know this", which decides what players see. Small.
7. **Put a Location card on the map as a point** — the natural first thing after importing a map. Medium.
8. **Player view shows the world map before the token is placed.** Small.
9. **Parchment seam + drop-down cut text** into the look checks, then fix what they find. Small.
10. **Enter logs in Quick-log; "Mark as met" from a logged note.** Small.
